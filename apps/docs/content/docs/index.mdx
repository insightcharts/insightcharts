Every chart takes a **title** that states one fact with its number, an entity to **highlight**, and **annotations** that mark a date, a threshold or a single value. The defaults follow common practice in news graphics. Lines and bars are labelled directly where possible. Bars start at zero. The highlighted series is drawn in colour and the other series in grey.

## Atomic Design

Atomic Design is a way of organising an interface as small parts that combine into larger ones. Brad Frost described it in 2013 with five levels named after chemistry: atoms, molecules, organisms, templates and pages. InsightCharts uses three of those names.

- An **atom** is the smallest part that is useful alone. Here that is one chart form or one figure primitive.
- A **molecule** is a few atoms combined to do one job. Here that is a combination that makes one point, such as a chart with a callout beside it.
- A **template** is a complete layout with places for content. Here that is a whole page or poster that takes its content as props.

InsightCharts has no organism level. A template filled with your data is the page.

| Level | What it is | Examples |
|---|---|---|
| [Atoms](/atoms) | One chart form or one figure primitive. | Bar chart, line chart, big number |
| [Molecules](/molecules) | A combination of atoms that is used often. | A row of statistics, a chart with a callout beside it |
| [Templates](/templates) | A complete page built from molecules and atoms. | A one-page executive brief, a scroll-driven essay |

Every component page lists what the component is built from and where it is used. For example, a big number is an atom. A stat row is a molecule that repeats the big number. The executive brief is a template that starts with a stat row.

## Features on every chart

Each chart is defined by one pure function that turns props and rows into an ECharts option. A shared factory supplies the features below, so they work the same way on every chart.

- **Data loading** from rows, columns, CSV text, a URL, an async function or an Arrow-style table, with JSON [transforms](/docs/data#transforms).
- **Figure text** as HTML: title, subtitle, legend, source line, and loading, empty and error states.
- **Theme and dark mode** resolved from CSS variables, following a shadcn/ui theme when one is present. See [theming](/docs/theming) and [dark mode](/docs/dark-mode).
- **Highlight and annotations**: see [highlighting and annotations](/docs/highlighting-and-annotations).
- **Crossfiltering** through a shared store: see [crossfiltering](/docs/crossfiltering).
- **Export** to PNG, JPEG, SVG, PDF, CSV and JSON: see [export](/docs/export). A whole poster or social card is saved as one PNG.
- **The `option` prop** for any ECharts setting that no prop covers: see [custom ECharts options](/docs/escape-hatch).

## Metadata for AI agents

InsightCharts pages are expected to be written mostly by AI agents and read by people. Each component carries machine-readable metadata: what it shows, when to use it, when to pick something else, its props and a working example. That metadata generates this site, [`llms.txt`](/llms.txt), a JSON Schema, a shadcn registry and an installable agent skill. See [for AI agents](/docs/ai-agents).
